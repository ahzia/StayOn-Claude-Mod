# Security policy

A Claude Code Mod runs with the same access as Claude Code on your machine, so we
take reports seriously.

Please report vulnerabilities privately through GitHub's
**Report a vulnerability** (Security tab) rather than a public issue. Include the
version, steps to reproduce and impact. We aim to reply within a week.

StayOn's own commitments: no network requests, no shell commands built from user
or file content, and no writes outside the project's task file and the plugin's
own store.
